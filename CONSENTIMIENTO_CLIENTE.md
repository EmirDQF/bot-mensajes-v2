CONSENTIMIENTO CLIENTE - BotMensajes (versión piloto)
=====================================================

Estimado cliente,

Gracias por probar nuestro servicio de atención y agendamiento por WhatsApp. Antes de empezar, por favor ten en cuenta lo siguiente:

1) Estado del conector
- Durante la fase piloto usaremos un conector no oficial (Baileys) para conectar WhatsApp con el bot. Esto nos permite arrancar rápido y realizar pruebas reales.

2) Riesgos
- Existe un riesgo bajo pero real de que WhatsApp restrinja temporalmente el número si detecta actividad automatizada no autorizada. En la mayoría de los casos la restricción es temporal y se puede recuperar la cuenta, pero queremos que lo sepas antes de iniciar pruebas.

3) Migración a la API oficial
- Si decides continuar después de la prueba piloto, ofrecemos migrar tu número a la API oficial de WhatsApp Cloud (Meta) sin costo adicional por nuestra parte. La API oficial reduce el riesgo de restricciones y es la opción recomendada para producción.

4) Qué esperamos del cliente
- Que el número a usar esté disponible para vincular con el QR en una prueba inicial (su teléfono deberá escanear el QR).
- Que nos informes si el número tiene políticas previas de uso empresarial o restricciones.

Si estás de acuerdo con lo anterior, responde "ACEPTO" por este chat y coordinamos la instalación y la prueba.
